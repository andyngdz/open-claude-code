Install Open Claude Code

Choose an OpenCode Go model once, then launch Claude Code through your local gateway.

curl -fsSL https://andyngdz.github.io/open-claude-code/install.sh | sh

For macOS and common Linux distributions. The script fetches the latest stable release.

macOS

Apple Silicon and Intel

Run the command above. It downloads the matching DMG and copies the app to Applications.

Linux

Debian, Ubuntu, Fedora and more

The script picks DEB on APT systems, RPM on DNF systems, then falls back to an AppImage with a searchable launcher and icon.

Windows

Windows 10 and later

Download the current MSI installer, run it, then open Open Claude Code from the Start menu.

Download Windows installer

After installation

Start a Claude Code session

  1. Open Open Claude Code and save an OpenCode Go API key.
  2. Select a model and workspace.
  3. Launch Claude Code from the app.
